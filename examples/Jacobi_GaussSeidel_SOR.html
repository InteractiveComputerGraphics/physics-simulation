Iterative solvers

Direct methods like the LU decomposition require $\mathcal{O}(n^3)$ operations and destroy the sparsity of a matrix (fill-in). For the large and sparse linear systems which occur in physics simulations, iterative methods are often preferred. Starting with an initial guess $\mathbf{x}^{(0)}$, they compute a sequence of approximations $\mathbf{x}^{(1)}, \mathbf{x}^{(2)}, \dots$ which hopefully converges to the solution of $A\mathbf{x} = \mathbf{b}$. Each iteration only costs about as much as a matrix-vector product, i.e. $\mathcal{O}(n)$ for a sparse matrix.

All methods are based on splitting the matrix in its strictly lower triangular part $L$, its diagonal $D$ and its strictly upper triangular part $U$:

$$A = L + D + U.$$

Jacobi method

The $i$-th equation is solved for the unknown $x_i$, where all other unknowns are taken from the previous iterate:

$$x_i^{(k+1)} = \frac{1}{a_{ii}}\left(b_i - \sum_{j \neq i} a_{ij}\, x_j^{(k)}\right), \qquad i = 1,\dots,n.$$

In matrix notation: $\mathbf{x}^{(k+1)} = D^{-1}\left(\mathbf{b} - (L + U)\,\mathbf{x}^{(k)}\right)$. All components can be computed independently, so the Jacobi method is easy to parallelize (e.g. on the GPU). However, a copy of the old iterate is required.

Gauss-Seidel method

Gauss-Seidel uses the same formula, but the new values $x_j^{(k+1)}$ of the components $j < i$ are used as soon as they are available:

$$x_i^{(k+1)} = \frac{1}{a_{ii}}\left(b_i - \sum_{j \lt i} a_{ij}\, x_j^{(k+1)} - \sum_{j > i} a_{ij}\, x_j^{(k)}\right), \qquad i = 1,\dots,n.$$

In matrix notation: $\mathbf{x}^{(k+1)} = (D + L)^{-1}\left(\mathbf{b} - U\,\mathbf{x}^{(k)}\right)$. The vector can be updated in place, and the method usually converges faster than Jacobi (for many matrices, e.g. the Poisson matrix, one Gauss-Seidel iteration is as good as two Jacobi iterations). But the components must be computed sequentially, which makes the parallelization more difficult. In the 2D plot you can see that Gauss-Seidel moves along the coordinate axes: each sub-step solves one equation exactly, i.e. it moves horizontally or vertically onto the line of that equation.

Successive over-relaxation (SOR)

SOR is a Gauss-Seidel iteration where each update is scaled with a relaxation parameter $\omega$. First the Gauss-Seidel value $\tilde{x}_i$ is computed, then the step from the old value towards $\tilde{x}_i$ is multiplied by $\omega$:

$$\tilde{x}_i = \frac{1}{a_{ii}}\left(b_i - \sum_{j \lt i} a_{ij}\, x_j^{(k+1)} - \sum_{j > i} a_{ij}\, x_j^{(k)}\right), \qquad x_i^{(k+1)} = (1-\omega)\, x_i^{(k)} + \omega\, \tilde{x}_i = x_i^{(k)} + \omega\left(\tilde{x}_i - x_i^{(k)}\right).$$

In matrix notation: $\mathbf{x}^{(k+1)} = (D + \omega L)^{-1}\left(\omega\mathbf{b} - \left(\omega U + (\omega - 1) D\right)\mathbf{x}^{(k)}\right)$.

  • $\omega = 1$: Gauss-Seidel.
  • $\omega > 1$ (over-relaxation): the method takes a larger step than Gauss-Seidel. In the 2D plot the iterates overshoot the line of the equation. If Gauss-Seidel approaches the solution slowly from one side, this can speed up the convergence dramatically.
  • $\omega \lt 1$ (under-relaxation): smaller steps, which can stabilize an iteration that oscillates or diverges.

SOR can only converge for $0 \lt \omega \lt 2$ (Kahan: $\rho(M_{SOR}) \geq |\omega - 1|$). If $A$ is symmetric positive definite, SOR converges for every $\omega \in (0, 2)$ (Ostrowski-Reich). The best choice of $\omega$ depends on the matrix. For consistently ordered matrices (e.g. tridiagonal matrices like the 1D Poisson matrix) the optimal value is known:

$$\omega_\text{opt} = \frac{2}{1 + \sqrt{1 - \rho(M_J)^2}}, \qquad \rho(M_{SOR}) = \omega_\text{opt} - 1.$$

For the 5x5 Poisson matrix we get $\rho(M_J) = \cos(\pi/6) \approx 0.866$, $\omega_\text{opt} = 4/3$ and $\rho(M_{SOR}) = 1/3$, compared to $\rho(M_{GS}) = 0.75$ for Gauss-Seidel.

Convergence

All methods have the form $\mathbf{x}^{(k+1)} = M\mathbf{x}^{(k)} + \mathbf{c}$ with the iteration matrix $M_J = -D^{-1}(L+U)$ (Jacobi), $M_{GS} = -(D+L)^{-1}U$ (Gauss-Seidel) or $M_{SOR} = (D + \omega L)^{-1}\left((1-\omega)D - \omega U\right)$ (SOR). The error $\mathbf{e}^{(k)} = \mathbf{x}^{(k)} - \mathbf{x}^*$ satisfies $\mathbf{e}^{(k+1)} = M\mathbf{e}^{(k)}$. Hence, the method converges for every initial guess if and only if the spectral radius $\rho(M) < 1$. The spectral radius is defined as the largest absolute value of the eigenvalues $\lambda_i$ of $M$: $\rho(M) = \max_i |\lambda_i|$. The smaller $\rho(M)$, the faster the convergence: in each iteration the error is reduced by about the factor $\rho(M)$.

Sufficient conditions which are easier to check:

  • If $A$ is strictly diagonally dominant, i.e. $|a_{ii}| > \sum_{j\neq i} |a_{ij}|$ for all $i$, both methods converge.
  • If $A$ is symmetric positive definite, Gauss-Seidel and SOR with $0 \lt \omega \lt 2$ converge (but Jacobi not necessarily, see example "3x3 SPD, Jacobi diverges").

Note that the order of the equations matters: In the example "2x2 not convergent" both methods diverge. If both equations are swapped, the matrix becomes diagonally dominant and both methods converge.

In practice the iteration is stopped when the residual $\|\mathbf{b} - A\mathbf{x}^{(k)}\|$ is small enough or a maximum number of iterations is reached. The convergence plot shows the residual of all methods on a logarithmic scale.

Relation to physics simulation

Position based dynamics solves its constraints in a (nonlinear) Gauss-Seidel fashion: one constraint after the other is projected and the updated positions are used immediately. Jacobi-style variants, where all constraints are processed in parallel and the corrections are averaged, are popular on the GPU. There, the averaged corrections are often scaled with a relaxation parameter $\omega$ (as in SOR) to speed up the convergence.
