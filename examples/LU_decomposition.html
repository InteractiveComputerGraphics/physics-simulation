LU decomposition

We want to solve the linear system $A\mathbf{x} = \mathbf{b}$ with a regular matrix $A \in \mathbb{R}^{n\times n}$. The idea of the LU decomposition is to factorize the matrix into a lower triangular matrix $L$ with ones on the diagonal and an upper triangular matrix $U$:

$$\begin{equation*} PA = LU. \end{equation*}$$

$P$ is a permutation matrix which records the row exchanges performed by pivoting. Since $P^{-1} = P^T$, it is cheap to store (as a vector of row indices) and to apply.

Algorithm

We start with $P = I$, $L = I$ and $U = A$. Then for each column $k = 1, \dots, n-1$ two steps are performed:

  1. Pivot step: Find the row $p \geq k$ with the largest absolute value $|u_{pk}|$ in column $k$ (partial pivoting). Swap the rows $k$ and $p$ in $U$ and in $P$. Additionally, the multipliers which were already computed in $L$ (columns $1,\dots,k-1$) are swapped, since they belong to the rows that are exchanged.
  2. Elimination step: For each row $i > k$ compute the multiplier $$l_{ik} = \frac{u_{ik}}{u_{kk}},$$ store it in $L$ and subtract the $l_{ik}$-fold of the pivot row from row $i$ of $U$: $$u_{ij} \leftarrow u_{ij} - l_{ik}\, u_{kj}, \qquad j = k, \dots, n.$$ This creates zeros below the pivot $u_{kk}$.

After every single step the invariant $PA = LU$ holds (see the check below the matrices). After the last column $U$ is upper triangular and the decomposition is complete. The computational effort is $\mathcal{O}(n^3)$.

Why pivoting?

Without pivoting the algorithm fails if a pivot $u_{kk}$ becomes zero (try the example "3x3 zero pivot" with pivoting disabled), although the matrix is regular. Even if the pivot is only small, the multipliers $l_{ik}$ become very large, which leads to large rounding errors (example "2x2 tiny pivot"). Choosing the largest element as pivot guarantees $|l_{ik}| \leq 1$, which makes the method numerically stable in practice.

Solving the system

With $PA = LU$ and $P^{-1} = P^T$ we get $A = P^T L U$. Hence, the system $A\mathbf{x} = \mathbf{b}$ becomes $P^T \underbrace{L \underbrace{U\mathbf{x}}_{\mathbf{y}}}_{\mathbf{z}} = \mathbf{b}$, which is solved in three steps:

  1. Permutation: solve $P^T\mathbf{z} = \mathbf{b}$:   $\mathbf{z} = P\mathbf{b}$ (just a reordering of the entries of $\mathbf{b}$)
  2. Forward substitution: solve $L\mathbf{y} = \mathbf{z}$:   $y_i = z_i - \sum_{j \lt i} l_{ij}\, y_j$
  3. Backward substitution: solve $U\mathbf{x} = \mathbf{y}$:   $x_i = \frac{1}{u_{ii}}\left(y_i - \sum_{j>i} u_{ij}\, x_j\right)$, starting with $i = n$

These steps only require $\mathcal{O}(n^2)$ operations. Hence, if the system has to be solved for many right-hand sides $\mathbf{b}$ with the same matrix $A$, the expensive decomposition is computed only once.
